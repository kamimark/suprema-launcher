# Suprema launcher

Launcher for **Suprema**, an early prototype of a Madner game (not yet playtested: expect rough edges).

The launcher is small. When you press **Update and play** it downloads the game from the game server (about 80 MB the
first time, only the changes after that), keeps it up to date and starts it. Everyone playing together is always on the
same version.

## Download
Get the newest zip from **[Releases](../../releases/latest)**:
- **Windows:** `suprema-launcher-windows-*.zip` → unzip → run `Suprema.exe`
  (if SmartScreen warns: *More info* → *Run anyway*; the launcher isn't code-signed).
- **Linux:** `suprema-launcher-linux-*.zip` → unzip → run `./suprema-launcher.x86_64`.

You only need a new launcher when a release note says so; game updates arrive by themselves.

## Playing
1. Start the launcher and press **Update and play**.
2. In the game's menu type your name and the **room password** (ask whoever invited you), then **Play online**.
3. The first player in the room hosts: ←/→ versus or co-op, ↑ 3v3 / 5v5, ↓ match length, Enter (or A) starts.
   Bots fill the empty slots.
4. If the server is down, the launcher can still start the last downloaded version for offline play against bots.

**Controls** (keyboard + mouse or a controller): move WASD · aim mouse · attack LMB/J · ranged RMB/K · special Q ·
dash Space · block Shift · ultimate R · interact F/E (hold) · level-up cards 1-4 · reroll T · map Tab · Esc shows all
controls · M mutes music.
